# Accounting Module - Quick Start Guide

## Sidebar Navigation

The Accounting module is now accessible from the main dashboard sidebar with the following structure:

```
📊 Accounting
   ├── 🔧 Setup & COA
   ├── 📝 Journals
   ├── 📖 Ledgers
   ├── 📊 Reports
   └── 📈 Analytics
```

## Page Access

### 1. Setup & COA

**URL:** `/dashboard/accounting/setup`
**Purpose:** Configure your accounting foundation

**What you can do:**

- ✅ Manage Chart of Accounts
- ✅ Create account categories and types
- ✅ Set up financial year periods
- ✅ Configure currencies and exchange rates
- ✅ Import accounts from Excel
- ✅ Set opening balances

**Quick Actions:**

- Click "Add Account" to create new accounts
- Click "Import Excel" to bulk upload accounts
- Switch between tabs to access different setup areas

---

### 2. Journals

**URL:** `/dashboard/accounting/journals`
**Purpose:** Record and manage financial transactions

**What you can do:**

- ✅ View all journal entries
- ✅ Create new journal entries
- ✅ Edit existing entries
- ✅ Reverse posted entries
- ✅ Attach supporting documents
- ✅ Bulk import from Excel

**Quick Actions:**

- Click "Create Entry" to record a new transaction
- Click "Bulk Import" to upload multiple entries
- Click edit icon to modify draft entries
- Click reverse icon to create reversing entry

---

### 3. Ledgers

**URL:** `/dashboard/accounting/ledgers`
**Purpose:** View detailed account activity

**What you can do:**

- ✅ View general ledger
- ✅ See account transaction history
- ✅ Drill down into debits and credits
- ✅ Filter by date range
- ✅ Export ledger data

**Quick Actions:**

- Select an account from the sidebar
- Set date range filters
- Click "Apply Filter" to refresh data
- Click "Export" to download ledger

---

### 4. Reports

**URL:** `/dashboard/accounting/reports`
**Purpose:** Generate financial statements

**What you can do:**

- ✅ Generate Balance Sheet
- ✅ Create Profit & Loss Statement
- ✅ View Trial Balance
- ✅ Generate Cash Flow Statement
- ✅ Filter by period (Annual, Quarterly, Monthly)
- ✅ Export to PDF or Excel

**Quick Actions:**

- Select report type from dropdown
- Choose period and date range
- Click "Generate Report"
- Click "Export PDF" or "Export Excel"

**Available Reports:**

1. **Balance Sheet** - Assets, Liabilities, Equity
2. **Profit & Loss** - Revenue, Expenses, Net Profit
3. **Trial Balance** - All account balances
4. **Cash Flow** - Cash movements (coming soon)

---

### 5. Analytics

**Purpose:** Visualize financial performance

**What you can do:**

- ✅ View key financial KPIs
- ✅ Analyze income vs expense trends
- ✅ See expense breakdown by category
- ✅ Review asset distribution
- ✅ Check financial ratios

**Key Metrics:**

- 💰 Total Revenue

## Common Workflows

### Workflow 1: Setting Up Accounting (First Time)

1. Go to **Setup & COA**
2. Create account categories
3. Add accounts to Chart of Accounts
4. Set financial year dates
5. Configure currency settings
6. Import existing accounts (if any)

### Workflow 2: Recording Transactions

1. Go to **Journals**
2. Click "Create Entry"
3. Enter date and description
4. Add journal lines (accounts, debits, credits)
5. Attach supporting documents
6. Save as draft or post immediately

### Workflow 3: Month-End Reporting

1. Go to **Ledgers** - Review all account balances
2. Go to **Reports** - Generate Trial Balance
3. Verify debits = credits
4. Generate Balance Sheet
5. Generate Profit & Loss Statement
6. Export reports to PDF
7. Go to **Analytics** - Review KPIs

### Workflow 4: Financial Analysis

1. Go to **Analytics**
2. Review KPI cards for quick overview
3. Analyze income vs expense trends
4. Check expense breakdown
5. Review financial ratios
6. Identify areas for improvement

## Tips & Best Practices

### Chart of Accounts

- Use consistent numbering (e.g., 1000s for Assets, 2000s for Liabilities)
- Create meaningful account names
- Group similar accounts under categories
- Don't create too many accounts initially

### Journal Entries

- Always include clear descriptions
- Attach supporting documents
- Verify debits = credits before posting
- Use draft status for entries under review
- Post entries only when verified

### Period Closing

- Review all entries before closing period
- Generate all required reports
- Export and archive reports
- Lock period to prevent changes

### Data Accuracy

- Reconcile accounts regularly
- Review ledgers monthly
- Compare reports period-over-period
- Investigate unusual variances

## Troubleshooting

**Issue:** Can't see accounting menu
**Solution:** Check user permissions, ensure accounting module is enabled

**Issue:** Debits don't equal credits
**Solution:** Review all journal lines, ensure balanced entry

**Issue:** Reports show incorrect data
**Solution:** Verify date range filters, check if all entries are posted

**Issue:** Can't export reports
**Solution:** Ensure browser allows downloads, try different format
